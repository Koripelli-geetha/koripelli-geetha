# HSBox Penetration Testing Lab

## Overview

This project documents a hands-on penetration testing exercise performed in an authorized HSBox lab environment.

The lab covers the penetration testing process from network reconnaissance and port scanning through vulnerability identification, exploitation, privilege escalation, and root-level access.

## Lab Objective

The objective of this lab is to understand the basic penetration testing methodology and gain practical experience with network scanning, service enumeration, vulnerability assessment, exploitation, and privilege escalation.

## Tools Used

- Kali Linux
- Nmap
- Metasploit Framework
- FTP Enumeration Tools
- SMB Enumeration Tools

## Methodology

The lab followed these general phases:

1. Network Scanning
2. Target Identification
3. Port Scanning
4. Service Enumeration
5. FTP Enumeration
6. Vulnerability Identification
7. SMB Vulnerability Assessment
8. Exploitation
9. Privilege Escalation
10. Root Access
11. Documentation

## Key Learning

Through this lab, I gained hands-on experience in:

- Identifying active hosts
- Finding open ports and services
- Performing service enumeration
- Identifying potential vulnerabilities
- Using Nmap for network reconnaissance
- Using Metasploit for authorized security testing
- Understanding privilege escalation
- Documenting penetration testing activities
